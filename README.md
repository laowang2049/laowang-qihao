# 老王起号

**给新号做前三条内容。** 三种类型，一句话就能开工。

> 老王 出品

---

## 三种是什么

| | 长什么样 | 你出什么 | 成本 |
|---|---|---|---|
| **1 单图互动** | 16:9 一张图，黑白线稿 + 顶部一句提问 | 只给赛道，文案我写 | 一张图 |
| **2 图文拼接** | 3:4 一张图，你的文案 + 配图 | 从抖音复制一段文案 | 一张图 |
| **3 vibe 知识大赏** | 代码动画，横版竖版都行 | 一个主题，加上你要的时长、画幅、背景音 | 不耗积分 |

第 1 种的成品：`assets/type1-example.jpg`
第 2 种的成品：`assets/type2-example.jpg`

**1 和 2 是发图，3 是发视频。** 1 的文案靠 AI 写（要勾评论区），2 的文案是你自己的（配热门原音频）。

## 怎么用

跟 AI 说一句就行：

> 用老王方法起号，帮我做个职场号

它会先弹一个三选一，你选完它就开始做。中间会问你这些：

- 第 1 种：赛道（职场 / 情感 / 育儿…），以及「生图要花积分，继续吗」
- 第 2 种：你的文案，以及「生图要花积分，继续吗」
- 第 3 种：**主题、时长（30 秒 / 1 分钟 / 2 分钟 / 自己填）、画幅（9:16 竖版 / 16:9 横版）、背景音（默认 vibe 增智小曲 / 自己上传 / 系统自动配）**，一条没给就一定会问，不会替你定

第 3 种的背景音是**开工前就要选**的，跟时长、画幅一个级别：默认那首是内置的成品音乐（`vendor/laowang-vibe-video/assets/bgm/vibe-bgm.mp3`），按片长裁好铺满；你也可以甩一个音频文件让它接；或者让它按片子情绪现场合成一段。

第 2 种做完，它会提醒你发布时选哪首音频——这条别忽略。

## 装

```bash
pip install pillow
```

Python 3.9+。第 3 种（代码动画）额外要 `playwright` + `ffmpeg`，内置的 vibe 里有 `doctor.py` 会告诉你缺什么：

```bash
cd vendor/laowang-vibe-video && python scripts/doctor.py
```

第 3 种的背景音不用另外装东西：内置小曲随仓库带着，现场合成用的是纯 Python 脚本。

## 手动用（不走对话也行）

```bash
# 排一张 3:4 的底稿：上面是字，下面是留白
python scripts/typeset.py --text "你的文案" --ratio 3:4 --out draft.jpg --json-out draft.json

# 看看排出来多少行、字号多大、占画幅多少（不出图）
python scripts/typeset.py --text "你的文案" --ratio 3:4 --analyze

# 生完图之后：只做规范化（模型把字画对了）
python scripts/compose.py --model 模型出的图.png --draft draft.json --out final.jpg

# 生完图之后：只取插画，把字重新贴一遍（模型把字画错了）
python scripts/compose.py --model 模型出的图.png --draft draft.json --out final.jpg --mode retext
```

## 排版是怎么定的

不是拍脑袋，是算出来的：

1. 先按文案排版，得到行数和高度
2. 文字区**不超过画幅 60%**，超了就缩字号（60→32px）
3. 剩下的才是插画区，模型只负责画那块
4. 所以文案多长都不会「留白太多/太少」

细节：断行优先落在标点、行首不出标点、行尾不出开引号、末行不许只剩一两个字、行距 1.75、左右边距 8.5%。

字数建议控制在 **200 字以内**（含标点）。超了字号会变小，手机上看着吃力——AI 会先提醒你再动手。

## 你做的图归谁

**归你。** 随便发、随便商用、随便接广告。这个仓库的协议管的是代码本身，不管你的产出。

## 它不做什么

- 不管你发什么、什么时候发——**只有第 2 种**会提醒你选原音频，其余不啰嗦。
- 不帮你养号、不刷数据。
- 不生成真人素材，画面要么是模型画的插画，要么是代码画的。
