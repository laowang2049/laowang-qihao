# 第 1 种：顶部文案提示词原文

这一条是老王定的，别自由发挥。原样存在这里，方便对齐。

---

根据我后面输入的赛道，输出 **1 句**图片顶部文案，规则：

1. **句式**：疑问句，场景具象化，自带情感留白，能勾起人内心故事，让人想打字分享自己的答案；
   不要立场对立争吵型提问，拒绝短视频烂大街俗套问句，不做观点辩论类问题。
2. **核心**：搭建具体假想场景，触发回忆与情绪，侧重内心故事表达，不是观点争辩。
3. **可以用假想假设句式开头**（如果 / 假如），或者「你觉得」「你认为」这样的开头。
4. **只输出文案**，不加任何额外文字。文案言简意赅，不要有阅读障碍。

---
